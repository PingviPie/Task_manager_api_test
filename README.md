# 🧪 Task Manager — QA Practice (Postman + json-server)

Локальный учебный стенд для практики REST API: GET, POST, PUT, PATCH, DELETE через Postman.

---

## 📁 Структура проекта

```
task-manager/
├── db.json       ← база данных (json-server)
├── index.html    ← фронтенд (открыть в браузере)
└── README.md     ← эта инструкция
```

---

## 🚀 Запуск за 2 шага

### Шаг 1 — Установить и запустить json-server

```bash
# Установить json-server глобально (один раз)
npm install -g json-server

# Перейти в папку проекта и запустить сервер
cd task-manager
json-server --watch db.json --port 3000
```

Ты увидишь:
```
Resources
  http://localhost:3000/tasks

Home
  http://localhost:3000
```

> ✅ Сервер работает, если нет ошибок в консоли.

### Шаг 2 — Открыть фронтенд

Просто открой файл `index.html` в браузере (двойной клик).

Фронт **автоматически обновляется каждые 3 секунды** — сразу видно результат любого запроса из Postman.

---

## 📬 Практика в Postman

Base URL: `http://localhost:3000`

---

### 1. GET — Получить все задачи

```
GET http://localhost:3000/tasks
```
- Headers: не нужны
- Body: не нужен
- Ожидаемый ответ: `200 OK`, массив задач

---

### 2. GET — Получить одну задачу по ID

```
GET http://localhost:3000/tasks/1
```
- Замени `1` на нужный id
- Ожидаемый ответ: `200 OK`, объект задачи
- Если не найдено: `404 Not Found`

---

### 3. POST — Создать новую задачу

```
POST http://localhost:3000/tasks
```

**Headers:**
```
Content-Type: application/json
```

**Body (raw → JSON):**
```json
{
  "title": "Протестировать API задач",
  "description": "Проверить все CRUD операции",
  "status": "todo",
  "priority": "high",
  "assignee": "Твоё имя"
}
```

- Ожидаемый ответ: `201 Created`, новый объект с `id`
- На фронте появится новая карточка

---

### 4. PUT — Полная замена задачи

```
PUT http://localhost:3000/tasks/1
```

**Headers:**
```
Content-Type: application/json
```

**Body (raw → JSON):**
```json
{
  "title": "Полностью обновлённая задача",
  "description": "Все поля заменены через PUT",
  "status": "in-progress",
  "priority": "medium",
  "assignee": "Новый исполнитель"
}
```

> ⚠️ PUT заменяет **весь** объект. Поля, которые не передал — удалятся!

- Ожидаемый ответ: `200 OK`
- На фронте карточка обновится

---

### 5. PATCH — Частичное обновление

```
PATCH http://localhost:3000/tasks/2
```

**Headers:**
```
Content-Type: application/json
```

**Body (raw → JSON):**
```json
{
  "status": "done"
}
```

> ✅ PATCH обновляет **только переданные поля**. Остальные данные сохраняются.

- Ожидаемый ответ: `200 OK`
- На фронте только статус поменяется

---

### 6. DELETE — Удалить задачу

```
DELETE http://localhost:3000/tasks/4
```

- Body и Headers: не нужны
- Ожидаемый ответ: `200 OK`, пустой объект `{}`
- На фронте карточка исчезнет

---

## 🎯 Учебные задания

1. **GET all** — получи все задачи, проверь статус ответа и количество объектов
2. **GET by ID** — получи задачу с id=2, проверь поля
3. **GET 404** — запроси задачу с id=999, убедись что пришёл 404
4. **POST** — создай задачу со своим именем в `assignee`, она появится на фронте
5. **PATCH** — смени статус своей задачи на `in-progress`, потом на `done`
6. **PUT** — полностью замени задачу, намеренно пропусти поле `assignee` — проверь что оно пропало
7. **DELETE** — удали задачу которую создал, убедись что 200 и карточка исчезла
8. **POST validation** — попробуй отправить пустой body `{}` — что вернёт сервер?

## ❓ FAQ

**Q: Фронт не видит данные / ошибка CORS**
A: Открывай `index.html` напрямую из файловой системы (не через другой сервер). json-server по умолчанию разрешает все CORS.

**Q: json-server не устанавливается**
A: Убедись что Node.js установлен: `node -v`. Если нет — скачай с [nodejs.org](https://nodejs.org).

**Q: После DELETE данные вернулись**
A: json-server пишет изменения в `db.json`. Если ты перезапустил сервер и данные восстановились — значит `db.json` не менялся. Проверь права на запись файла.

**Q: Как сбросить данные к начальным?**
A: Останови сервер, восстанови `db.json` из резервной копии (или скопируй начальное содержимое из README), запусти сервер заново.
